# Русская документация

Русская часть предназначена для быстрой ориентации.

Canonical технические спецификации ведутся на английском в docs/00–07, чтобы API, units, crate names и semantic contracts не расходились между переводами.

## Читать

- [MVP_PLAN_RU.md](MVP_PLAN_RU.md) — первоначальный master-plan, сохранённый как исторический/планировочный контекст.
- [Implementation Readiness](../07-planning/IMPLEMENTATION_READINESS.md) — formal gate перед кодом.

При противоречии русской сводки и Accepted English spec источником истины является English spec; расхождение нужно исправить, а не поддерживать две версии.
