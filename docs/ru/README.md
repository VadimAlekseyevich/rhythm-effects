# Русская документация

Этот раздел хранит русскоязычные обзорные и планировочные документы.

Технические спецификации в `docs/` ведутся на английском, чтобы кодовые термины, API и названия библиотек не расходились между переводами.

## Сейчас

- [MVP_PLAN_RU.md](MVP_PLAN_RU.md) — общий план от нуля до MVP.
- Оригинальная копия также остаётся в корне репозитория: [../../MVP_PLAN.md](../../MVP_PLAN.md).

При необходимости сюда можно добавлять русские summary-файлы, но не следует поддерживать две независимые технические спецификации одной системы.
